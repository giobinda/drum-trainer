# Drum Trainer & Metronome – website

The website of the Drum Trainer & Metronome Android app, served by GitHub Pages at
https://giobinda.github.io/drum-trainer/

- `index.html` (English) and `de/index.html` (German) are generated: edit the texts in `build.py`
  and run `python3 build.py`.
- `privacy/` is the privacy policy (English and German); the app links to it.
- `assets/` holds the stylesheet, the icon and the screenshots.
